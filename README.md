# 🛡️ CodeAlpha Cybersecurity Projects

A collection of practical cybersecurity projects developed during my **CodeAlpha internship**, demonstrating skills in **Phishing Awareness, Secure Coding, Web Security, and Cyber Incident Management**.

---

## 📂 Projects

### 🎣 1. PhishGuard — Phishing Awareness

An interactive web-based platform designed to educate users about phishing and social engineering attacks.

**Key Features:**
- 📧 Email phishing awareness
- 🌐 Fake website awareness
- 🎭 Social engineering education
- 🎯 Phishing attack simulator
- 🧠 Interactive security quiz
- 📊 Human risk dashboard
- 📚 Real-world phishing examples

**Technologies:**  
`HTML` `CSS` `JavaScript`

📁 Project: `PhishGuard/`

---

### 🔐 2. CyberIncident — Secure Coding Review

A Flask-based cybersecurity application for **cyber incident reporting, tracking, automated workflow, and security review**.

**Key Features:**
- 🔑 User registration and login
- 🔒 Password hashing
- 🚨 Cyber incident reporting
- 📊 Incident tracking
- 🔍 Security indicator/IP detection
- ⚙️ Automated investigation workflow
- 👨‍💻 SOC analyst review workflow
- 📝 Secure coding review documentation

**Technologies:**  
`Python` `Flask` `SQLAlchemy` `SQLite` `HTML` `CSS`

📁 Project: `CyberIncident_SecureReview/`
