# 🎣 Project 1 — PhishGuard

## 📌 Overview

**PhishGuard** is an interactive phishing awareness platform designed to help users understand and identify common phishing and social engineering attacks.

The project focuses on **security awareness training** rather than real-world exploitation.

It provides educational content, examples, quizzes, and interactive simulations to demonstrate how attackers attempt to manipulate users.

### 🎯 Objectives

- Educate users about phishing attacks
- Explain common social engineering techniques
- Demonstrate how malicious emails can appear legitimate
- Teach users how to identify suspicious websites
- Improve security awareness through interactive learning
- Provide practical examples of phishing indicators
- Help users develop safer online habits

---

## ✨ Features

### 📧 Email Phishing Awareness

Explains common phishing email characteristics including:

- Suspicious senders
- Urgent requests
- Malicious links
- Unexpected attachments
- Fake security alerts
- Social engineering techniques

### 🌐 Fake Website Awareness

Demonstrates common indicators of fraudulent websites:

- Suspicious URLs
- Fake login pages
- Look-alike domains
- Untrusted links
- Credential harvesting risks

### 🎭 Social Engineering Education

Explains techniques attackers use to manipulate victims, including:

- Urgency
- Fear
- Authority
- Curiosity
- Trust exploitation

### 🎯 Phishing Attack Simulator

Provides an educational simulation showing how a phishing scenario can work and helps users understand the warning signs.

### 🧠 Security Quiz

Interactive quizzes help users test their knowledge of phishing and cybersecurity awareness.

### 📊 Human Risk Dashboard

Provides a conceptual view of user security awareness and risk indicators.

### 📚 Real-World Examples

Educational examples demonstrate common phishing scenarios and attack patterns.
